# Sasobhabha M3th

## How do I install these formulae?

`brew install sasobhabha/m3th/<formula>`

Or `brew tap sasobhabha/m3th` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sasobhabha/m3th"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
